# DYM'S - Sistema POS y Gestión Agropecuaria

Sistema de Punto de Venta (POS), Control de Inventario, Cuadre de Caja y Facturación para Distribuidora DYM'S.

- **Frontend**: Next.js (App Router), Tailwind CSS, Lucide Icons.
- **Backend & Base de Datos**: Supabase.
- **Funcionalidades**:
  - Control de Caja (Apertura y Cierre con arqueo de dinero en efectivo).
  - Facturación rápida con tickets para clientes y notificación al dueño por WhatsApp.
  - Gestión de inventario con alertas de stock mínimo.
  - Anulación de ventas y devolución automática al stock (Solo Administrador).
  - Resúmenes diarios y reportes exportables a Excel.
